beforeinstallprompt API contract:
- Event fires on the `window` once per page load when criteria are met.
- Must call `event.preventDefault()` to prevent the default mini-infobar (so the app can show its own UI later).
- Stash the event; later call `event.prompt()` to show the native install dialog.
- After `prompt()`, `event.userChoice` resolves to `{ outcome: 'accepted' | 'dismissed', platform: string }`.
- `appinstalled` event fires on `window` when the app is successfully installed.

iOS Safari detection:
- No `beforeinstallprompt` support — must detect environment instead.
- `navigator.standalone === true` → already installed (in standalone mode).
- iOS Safari UA check: `/iPad|iPhone|iPod/.test(navigator.userAgent) && !window.MSStream` AND `'standalone' in navigator` (the second check distinguishes Safari from in-app browsers like Instagram which lack it).
- Display-mode check: `window.matchMedia('(display-mode: standalone)').matches === true` → already installed (covers Android+desktop installed case).

  <behavior>
    The service is the single source of truth for "can the user install this PWA?" State machine:

    - `init()` registers `beforeinstallprompt` and `appinstalled` listeners on `window`. Idempotent — calling twice does not double-register; remove stale listeners before re-adding (mirror theme.js pattern).
    - On `beforeinstallprompt`: call `event.preventDefault()`, stash the event in module-scoped state, then invoke any subscribed change callback so the UI can re-render.
    - On `appinstalled`: drop the stashed event and notify subscribers (button must hide).
    - `getStatus()` returns one of: `'installable'` (beforeinstallprompt fired, not in standalone), `'ios-instructions'` (iOS Safari, not in standalone, no beforeinstallprompt), `'installed'` (in standalone mode), `'unsupported'` (none of the above).
    - `isStandalone()` returns true if `window.matchMedia('(display-mode: standalone)').matches` OR `navigator.standalone === true`. Wrap in try/catch — return false on error.
    - `isIOSSafari()` returns true if `/iPad|iPhone|iPod/.test(navigator.userAgent)` AND `'standalone' in navigator` AND NOT `window.MSStream`. Wrap in try/catch.
    - `promptInstall()` returns a Promise that resolves to `{ outcome: 'accepted' | 'dismissed' | 'unavailable' }`. If a stashed event exists, call `.prompt()`, await `.userChoice`, and on `'accepted'` drop the stashed event + notify subscribers (button hides). On `'dismissed'`, keep the stashed event (button stays visible — no aggressive re-prompt, but allow another tap). If no stashed event, resolve `{ outcome: 'unavailable' }`.
    - `onChange(callback)` registers a single subscriber; returns an unsubscribe function. The service calls the subscriber whenever status changes (event capture, install, etc.). Replace the previous subscriber if `onChange` is called twice — keep it simple, single-consumer.
    - `destroy()` removes window listeners, clears stashed event, clears subscriber. Mirrors theme.js `destroy()` shape.
